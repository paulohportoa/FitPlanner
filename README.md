# FitPlanner AI

Aplicativo web offline para registrar e acompanhar o programa de treino.

## Como usar
1. Abra `index.html` no navegador.
2. Na aba **Treino**, selecione o treino e registre carga, repetições, RPE e execução de cada série.
3. Use **Histórico** para acompanhar as sessões.
4. Use **Progresso** para registrar peso, percentual de gordura e cintura.
5. Use **Check-in** ao final de 4 semanas.

Os registros ficam salvos no armazenamento local do navegador (localStorage).

## Observação
Para instalar como PWA em celular/desktop, sirva os arquivos por HTTPS ou por um servidor local. Abrir `index.html` diretamente funciona para o registro, mas alguns navegadores não ativam o modo PWA nesse cenário.
